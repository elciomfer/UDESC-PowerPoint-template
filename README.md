## Aviso

Este é um repositório **não oficial** e não possui vínculo institucional com a UDESC.

As marcas, elementos gráficos, identidade visual e demais materiais institucionais presentes no arquivo permanecem pertencentes aos seus respectivos titulares. A disponibilização do arquivo neste repositório não implica transferência de direitos sobre esses elementos.

Caso a UDESC disponibilize oficialmente este template, recomenda-se utilizar a versão disponibilizada pelos canais institucionais.
